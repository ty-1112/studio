# **App Name**: BugMed Labs

## Core Features:

- Homepage Design: Display a modern, clean homepage showcasing BugMed Labs' mission and values.
- Team Profiles: Feature detailed profiles of key personnel with expertise in medical entomology.
- Service Listings: Provide detailed descriptions of all lab services, along with available resources.
- Document Summarizer: Use a generative AI tool to let users summarize large documents.
- Contact Forms: Embed forms for contact, service requests, and media inquiries.
- Article Sharing: Allow the ability to share all articles.
- Interactive Maps: Feature interactive maps of regions BugMed Labs serves.

## Style Guidelines:

- Primary color: A deep forest green (#228B22) evokes the natural sciences.
- Background color: A very light off-white (#F5F5DC), near the primary hue.
- Accent color: A muted gold (#B8860B) to bring out textual features, against a background of green.
- Body and headline font: 'Alegreya', a serif typeface that provides an elegant and contemporary feel for both headlines and body text, for comfortable reading.
- Use high-resolution, detailed vector icons to represent lab services and team expertise. These icons will mimic the colors provided above.
- Employ a grid-based layout with generous whitespace to enhance readability and navigation, use full-width sections to highlight content.
- Incorporate subtle scrolling animations to enhance the user experience. Any animations should avoid obscuring or distracting users from key information.
